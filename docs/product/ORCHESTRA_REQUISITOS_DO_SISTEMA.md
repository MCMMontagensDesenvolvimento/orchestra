# Orchestra - Requisitos Do Sistema

Status: baseline operacional.

## Requisitos Funcionais Iniciais

- Gerenciar assistentes de IA.
- Configurar comportamento, conhecimento, ferramentas e publicacao.
- Usar assistentes em experiencia de chat.
- Exibir estados de loading, vazio, erro e acesso negado.
- Expor trilhas visuais de governanca e auditoria.

## Requisitos Nao Funcionais Iniciais

- Desenvolvimento local com WSL/Docker.
- Separacao clara entre frontend e backend futuro.
- Mocks controlados por ambiente.
- Base preparada para typecheck, build, lint e testes.

## Pendencias De Definicao

- Autenticacao real.
- RBAC/ABAC.
- Persistencia.
- Auditoria real.
- Observabilidade.
- Integracoes externas.
