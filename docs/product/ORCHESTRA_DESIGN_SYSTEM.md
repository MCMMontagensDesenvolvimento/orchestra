# Orchestra - Design System

Status: baseline operacional.

## Base Atual

O frontend usa Tailwind CSS, shadcn/ui, Radix UI e lucide-react. A UI ja possui polimento inicial de responsividade, acessibilidade basica e estados visuais para loading, empty, error e forbidden.

## Direcao

- Manter interface corporativa, clara e orientada a operacao.
- Preservar consistencia de componentes existentes.
- Evitar refatoracoes visuais amplas ate a arquitetura de produto estar estabilizada.

## Proximos Passos

- Auditar componentes compartilhados.
- Documentar tokens visuais.
- Definir padroes de formularios, tabelas, navegacao, estados e feedback.
