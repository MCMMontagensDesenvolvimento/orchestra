# Orchestra - Contexto Inicial Do Projeto

Status: operacional inicial.

Orchestra e uma plataforma corporativa para criacao, configuracao, publicacao, uso, governanca e auditoria de assistentes de IA.

O frontend atual esta disponivel em `/frontend`, ja preparado para desenvolvimento local com Vite, React, TypeScript, Tailwind CSS, TanStack Query e mocks controlados por variaveis `VITE_*`.

Backend real, banco de dados, autenticacao real, RAG real, MCP real e runtime real ainda nao estao implementados.

## Objetivo Da Proxima Fase

Definir a arquitetura de software e preparar o caminho para backend, APIs, banco, seguranca, infraestrutura e orquestracao de IA.
