# Orquestra — Documentação

Este diretório concentra a documentação oficial do projeto Orquestra.

## Estrutura

```txt
docs/
├── decisions/
├── governance/
├── product/
├── architecture/
├── engineering/
├── security/
├── project-management/
├── stakeholders/
└── support/
```

## Diretórios

### `decisions/`

Registro de decisões do projeto.

### `governance/`

Diretrizes corporativas de documentação e governança do projeto.

### `product/`

Documentação de produto, contexto, brief, discovery, requisitos e especificação funcional.

### `architecture/`

Documentação de arquitetura, orquestração de IA, APIs, contratos e banco de dados.

### `engineering/`

Documentação de frontend, backend, infraestrutura, CI/CD, observabilidade e qualidade.

### `security/`

Documentação de segurança, compliance, autenticação, autorização, auditoria e dados sensíveis.

### `project-management/`

Documentação de marcos, métricas, acompanhamento do MVP e snapshots técnicos.

### `stakeholders/`

Levantamentos, entrevistas e insumos coletados com stakeholders.

### `support/`

Roteiros e materiais auxiliares de apoio ao projeto.
