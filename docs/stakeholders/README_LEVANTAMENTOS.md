# Entregáveis — Decisões Iniciais do Orquestra

Este pacote contém:

1. `decision-log.md`  
   Arquivo inicial de decisões já firmadas do projeto Orquestra.  
   Caminho futuro recomendado no repositório:  
   `orquestra/docs/decisions/decision-log.md`

2. `QUESTIONARIO_DECISOES_PENDENTES_VITOR.md`  
   Questionário para validar pendências de produto, permissões, compartilhamento, workspaces, criação de assistentes, IA, Agno, segurança e escopo de MVP.

## Como usar

1. Enviar o questionário para Vitor.
2. Consolidar respostas.
3. Atualizar o `decision-log.md` com novas decisões.
4. Usar as decisões para preencher os próximos documentos do fluxo do projeto.
